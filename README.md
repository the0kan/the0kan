### [Machine Learning Systems Lab](https://github.com/the0kan/machine-learning-lab)

My ML systems coursework, starting with a reproducible comparison of Logistic Regression and Random Forest on the Breast Cancer Wisconsin dataset.

With a fixed, stratified 70/30 train/test split, Logistic Regression reached **98.83% test accuracy**. I also measured training and inference time, saved model size and process memory to compare the deployment trade-offs.

**Python · scikit-learn · Benchmarking**
